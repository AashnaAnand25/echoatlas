How to read these layers

What a mask shows

A mask outlines the pixels that someone (the annotation) or something (the model) marked as the lesion. It helps you see where to look and how the margins were drawn.

What it cannot establish

A mask does not say what a lesion is. Outlining a region is not a diagnosis, and a neat outline does not mean the model's label is right. Imaging alone cannot replace the clinical work-up.

Annotation vs. model

The dataset annotation is a reference drawn for the dataset. The model mask is a prediction. When they disagree, that is a good learning moment — not an error report.

Key terms
  • Lesion: an area that looks different from the tissue around it.
  • Margin: the edge of a lesion (smooth, irregular, angular…).
  • Segmentation: outlining the lesion pixel by pixel.
  • Classification: assigning a category such as benign or malignant.
  • Dice / IoU: scores for how well two outlines overlap (1.0 = identical).
  • Reference label: the label in the dataset, not a diagnosis of anyone.

Sources & Ethics

Dataset attribution, evaluation protocol, limitations, and the educational boundary.

Dataset attribution

The case source is the Breast Ultrasound Images Dataset (BUSI), with 780 images across normal, benign, and malignant classes and expert lesion masks. The project uses a CC BY 4.0 mirror of the original dataset by Al-Dhabyani et al.

  • Official BUSI dataset page
  • BUSI mirror and data-quality notes (CC BY 4.0)
  • Original dataset paper (Data in Brief, doi:10.1016/j.dib.2019.104863)
  • Raw images are not redistributed in this repository; download and cite the dataset from the source.

The app's workstation interface is adapted from the MIT-licensed atleekumaar/brain-tumor-mri-classifier project.

Global atlas metadata

The atlas reads public dataset metadata from the community-maintained Breast Ultrasound OpenHub catalog. EchoAtlas refreshes its README table through a cached server endpoint; it does not download or host those datasets.

  • Counts are reported samples per catalog entry, not a de-duplicated global case total. Entries may overlap.
  • Map markers indicate the collection/source country as cataloged, not the residence or location of individual patients.
  • This demo loads a small BUSI example subset. Other entries link to their source and may require separate access or have non-commercial terms.
  • No C3 AI tenant or API connection is configured. The live refresh reads the public GitHub README; no credentials are stored in this public repository.

Split protocol & metrics

  • The provided split groups exact and near-duplicate candidates, then stratifies by image label. BUSI has no reliable public patient IDs, so it is not a patient-level split.
  • Horizontal-flip augmentation is applied to the training split only.
  • Segmentation is reported with Dice and IoU on held-out cases.
  • Three-class classification (normal, benign, malignant) is reported with accuracy, balanced accuracy, macro-F1, and macro mAP.
  • Any earlier score from a different dataset (for example a prior 94.3% result) is not assumed to transfer.

Limitations

  • Small, single-collection dataset; results may not generalize to other scanners, sites, or populations.
  • BUSI has no reliable public patient IDs. The duplicate audit flags 124 candidate groups, including 8 groups that cross source labels. Results are image-level and exploratory, not patient-level validation.
  • Illustrative placeholder cases in this demo are generated pictures, not real patient scans.
  • No fabricated model output is ever shown: when no trained checkpoint is loaded, the app says so.
